# Calorie Tracker Projects

This public repository contains two implementations:

- **[RasoiTrack](./rasoitrack/)** — a React/Vite Indian-cuisine nutrition tracker with photo and text-based meal analysis, account sign-in, nutrition summaries, and a persistent food diary.
- **Original Python app** — the existing `app.py` and `requirements.txt` at the repository root. These files are preserved.

See [rasoitrack/README.md](./rasoitrack/README.md) for RasoiTrack's features, architecture, and AppDeploy deployment notes.

Live application: https://rasoitrack-5knt0m.v2.appdeploy.ai/
